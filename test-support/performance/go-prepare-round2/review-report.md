## Resolved finding

**P2 — An ambiguous invalid-parameters reply could bypass a canonical-state refusal.** The initial candidate converted every JSON-RPC `-32602` reply into a cached negative capability. A provider returning this code for an unknown hash could trigger a numeric retry and journal insertion if a backend then served the original header at that height. EIP-1898 recommends particular error codes for missing and noncanonical blocks and permits implementations to distinguish them differently. The revised classifier accepts `-32601` and two exact selector-format messages for `-32602`. The session tests now require ordinary invalid parameters, unknown block, noncanonical hash, pruned state and malformed hash at that same code to fail before numeric reads or journal insertion.
